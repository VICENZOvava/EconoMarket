##  Sobre o Projeto
 
O **EconoMarket** é uma aplicação desenvolvida para facilitar a comparação de preços entre diferentes mercados. A plataforma permite que o usuário consulte os preços dos produtos de sua lista de compras e identifique onde sua compra terá o menor custo.

Além da comparação individual dos produtos, o sistema apresenta o valor total da compra em cada mercado, permitindo visualizar de forma rápida quanto pode ser economizado. Para tornar as informações mais intuitivas, o EconoMarket conta com recursos visuais como **destaque do menor preço, identificação de promoções, selo de “Melhor Opção” e gráficos comparativos.**

O projeto também possui funcionalidades voltadas ao gerenciamento de produtos, mercados e preços, organizando as informações em uma interface simples e intuitiva.

O objetivo do EconoMarket é tornar a pesquisa de preços mais prática e ajudar o usuário a **tomar decisões de compra de forma rápida, visual e econômica.**
